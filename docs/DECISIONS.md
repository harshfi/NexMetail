# Owner decisions & supplied content

Answers from the owner after the brief (2026-10-04). Reference screenshots: [reference/](reference/).

## Accepted recommendations

- Buttons: use `copper-dark` (#8F5A2C) as the default button background, with `copper` (#B5763F) for hover and decoration. White text on copper alone fails AA for small text.
- `muted` text: only on white surfaces or at large sizes; darken it slightly if it's needed on `bg`.
- Fonts: load Bebas Neue and DM Sans only. Oswald is a CSS fallback name and is not downloaded.
- Map: Google Maps embed searched by the registered address until the owner supplies a pin.
- Stats: show only facts we can back up (GST-registered since 2019, number of grades, regions served).
- Form: honeypot field plus basic rate limit. The Resend sending domain must be verified before launch.
- Inner pages: dark page-title band, so the header still reads well where there's no hero.
- Privacy policy and terms: Claude drafts these (Indian B2B context), marked "for legal review".

- Palette: switched from the brief's warm off-white/brown-black to midnight navy (`#0A1322`) and cool steel neutrals (`#F3F5F8` background), keeping copper as the accent, so the site is visually distinct from glorax.in. Every text/background pair is checked for WCAG AA.
